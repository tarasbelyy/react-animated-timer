# Анимированный таймер


## Описание
Таймер с установкой времени, сбросом, перезапуском и круговой анимацией


## Инструкция 
Для запуска приложения из консоли наберите:
```
npm start
```
После запуска приложение доступно из браузера:
```
http://127.0.0.1:3000
```


## Функциональность
- при установке времени осуществляется проверка вводимого значения: от 1 до 99 минут
- показываются браузерные оповещения: ежеминутные и при завершении заданного интервала
- для включенного таймера поддерживаются перезапуск и сброс до исходного значения


## Требования
Основные библиотеки и фреймворки для JavaScript, используемые в проекте: 
- react версии 19.2.8
- react-dom версии 19.2.8
- react-scripts версии 5.0.1
